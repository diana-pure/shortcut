# Задание 3 — Промежуточные операции: sorted, distinct, limit, skip ⭐

## Цель
Освоить операции форматирования потока: сортировку, удаление дублей, ограничение и пропуск.

## Условие

В классе `StreamTransformations` реализуйте четыре метода:

### Часть A
```java
public List<Integer> sortedUnique(List<Integer> numbers)
```
Вернуть список **уникальных** чисел, отсортированных по возрастанию.

### Часть B
```java
public List<String> topNLongest(List<String> words, int n)
```
Вернуть `n` самых длинных слов (по убыванию длины).
Если слова одинаковой длины — сохранить их в алфавитном порядке между собой.

### Часть C
```java
public List<Integer> skipAndLimit(List<Integer> numbers, int skip, int limit)
```
Пропустить первые `skip` элементов, затем взять не более `limit` элементов.

### Часть D
```java
public List<Integer> uniqueSortedDescending(List<Integer> numbers)
```
Вернуть список уникальных чисел в порядке **убывания**.

## Требования
- Реализовать каждый метод через Stream API.
- Не использовать циклы.
- Методы должны корректно работать с пустым списком.

## Вопрос для размышления
`sorted()` — промежуточная или терминальная операция?
Можно ли вызвать `sorted()` после `limit()`? Что произойдёт?
