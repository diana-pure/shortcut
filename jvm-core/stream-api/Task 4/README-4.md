# Задание 4 — flatMap: работа с вложенными коллекциями ⭐⭐

## Цель
Понять разницу между `map` и `flatMap`. Научиться «раскрывать» вложенные структуры данных.

## Предварительное чтение

`map` заменяет каждый элемент на другой (один к одному).
`flatMap` заменяет каждый элемент на **поток** и «сплющивает» результат:

```
map:     [a, b, c]  →  f(a), f(b), f(c)         = [f(a), f(b), f(c)]
flatMap: [a, b, c]  →  [x,y], [z], [w,v]         = [x, y, z, w, v]
```

## Условие

В классе `StreamFlatMap` реализуйте три метода:

### Часть A
```java
public List<Integer> flattenLists(List<List<Integer>> nested)
```
Вернуть один список, содержащий все числа из всех вложенных списков (в порядке следования).

### Часть B
```java
public List<String> extractWords(List<String> sentences)
```
Дан список предложений. Вернуть список всех слов из всех предложений.
Разделитель слов — пробел.

Пример: `["hello world", "foo bar"]` → `["hello", "world", "foo", "bar"]`

### Часть C
```java
public List<Integer> uniqueNumbers(List<List<Integer>> nested)
```
Вернуть список **уникальных** чисел из всех вложенных списков, отсортированных по возрастанию.

## Требования
- Реализовать каждый метод через Stream API с использованием `flatMap`.
- Не использовать циклы.
- Методы должны корректно работать с пустыми списками.

## Вопрос для размышления
Что вернёт `stream().map(...)`, если функция возвращает `Stream<String>`?
Почему в этом случае нужен `flatMap`, а не `map`?
