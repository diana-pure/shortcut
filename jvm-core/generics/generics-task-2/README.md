# Задание 2 — Обобщённые методы

## Цель
Научиться писать обобщённые (generic) методы.

## Условие
В классе `CollectionUtils` реализуйте два статических обобщённых метода:

### Часть A
```java
public static <T> void printArray(T[] array)
```
Метод должен вывести в консоль все элементы массива (в порядке следования).

### Часть B
```java
public static <T> T getFirst(List<T> list)
```
Метод должен вернуть первый элемент списка.

## Требования
- Не использовать `Object` и приведения типов (cast).
- Обработать некорректные входные данные (например, `null` и/или пустой список) — на ваше усмотрение,
  но так, чтобы решение было предсказуемым.
- Без raw-типов.

## Как проверить
```bash
mvn test
```
