# Задание 1 — Обобщённый контейнер (Box<T>)

## Цель
Закрепить понимание параметризованного класса (`class Box<T>`).

## Условие
Реализуйте класс `Box<T>`, который:
- хранит одно значение типа `T`;
- имеет конструктор, принимающий `T`;
- имеет методы:
  - `T get()` — вернуть значение,
  - `void set(T value)` — записать новое значение.

## Требования
- Не использовать `Object` внутри `Box` (ни поле, ни методы).
- Не использовать приведение типов (cast).
- Код должен компилироваться без предупреждений об unchecked операциях.

## Как проверить
Запустите тесты:
```bash
mvn test
```

Тесты находятся в `src/test/java/...`.
