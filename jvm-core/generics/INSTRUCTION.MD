# Инструкция по работе с практическими заданиями по дженерикам

Данная инструкция предназначена для студентов, выполняющих практические задания 1–5 по теме **Generics в Java**.

---

## 1. Подготовка окружения

Перед началом работы убедитесь, что у вас установлены:

- JDK 17 (или выше)
- Maven 3.8+
- IDE (IntelliJ IDEA / Eclipse / VS Code)

Проверка версии Java:

    java -version

Проверка версии Maven:

    mvn -version

## 5. Правила выполнения

### Запрещено

- Использовать raw-типы (List вместо List<T>)
- Использовать приведение типов ((T) obj)
- Использовать Object вместо обобщённого типа
- Подавлять предупреждения через @SuppressWarnings

### Разрешено

- Использовать ограничения типа (<T extends Number>)
- Использовать wildcard'ы (? extends, ? super)
- Бросать осмысленные исключения (IllegalArgumentException)

---

## 6. Методика решения

### Если метод читает элементы из коллекции:

Используйте:

    ? extends T

(Producer Extends)

---

### Если метод добавляет элементы в коллекцию:

Используйте:

    ? super T

(Consumer Super)

---

### Если метод и читает, и пишет:

Обычно нужен конкретный параметризованный тип без wildcard.

---

## 7. Как понять, что решение корректное

Ваше решение считается корректным, если:

- проект компилируется
- тесты проходят
- нет предупреждений компилятора
- сигнатуры методов соответствуют заданию

После успешного выполнения задания попробуйте ответить:

1. Почему дженерики в Java инвариантны?
2. Почему List<Integer> не является List<Number>?

4. Почему компилятор запрещает добавление элементов в List<?>?

Если вы можете объяснить это без подсказок — задание усвоено.
