# Задание 5 — Инвариантность и проектирование API (дженерики)

## Цель
Понять:
- что такое **инвариантность** дженериков в Java;
- почему `Repository<AdminUser>` **не является** подтипом `Repository<User>`;
- как проектировать методы API с использованием wildcard'ов: `? extends` и `? super`;
- почему `List<?>` почти бесполезен, когда метод должен **добавлять** элементы.

если нужно сохранять типизированные сущности.

## Условия и ограничения
- Нельзя использовать raw-типы (`List` без параметра типа).
- Нельзя использовать приведение типов (cast) для обхода ограничений компилятора.
- Нельзя менять смысл задания: решение должно использовать wildcard'ы в сигнатурах методов.
- Код должен компилироваться без unchecked warning.

## Подсказка: PECS
- **Producer Extends** — источник, из которого мы читаем элементы: `? extends ...`
- **Consumer Super** — приёмник, в который мы добавляем элементы: `? super ...`
