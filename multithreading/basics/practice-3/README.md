# Практическое задание: Совместное использование объектов

## Описание тестов

### testMutableValueSynchronization
Проверяет, что `MutableValue` корректно синхронизирует доступ к полю `value`. Без синхронизации несколько потоков могут увидеть устаревшие данные.

### testUnsafePlaylistReturnsDefensiveCopy
Проверяет, что `UnsafePlaylist.getPlaylist()` возвращает копию внутреннего массива. Изменение возвращённого массива не должно влиять на внутреннее состояние объекта.

### testThreadLocalIsolation
Проверяет, что `ThreadLocalCounter` изолирует счётчик для каждого потока. Каждый поток должен видеть только свои инкременты.

### testImmutablePoint
Проверяет, что `ImmutablePoint` является истинно иммутабельным: все поля `final`, сеттеров нет, значения корректно инициализируются через конструктор.

## Классы для реализации

- **MutableValue**: Добавьте синхронизацию к методам `getValue()` и `setValue()`
- **UnsafePlaylist**: Исправьте `getPlaylist()`, чтобы возвращать защитную копию массива
- **ThreadLocalCounter**: Реализуйте изолированный счётчик через `ThreadLocal<Integer>`
- **ImmutablePoint**: Сделайте объект иммутабельным: `final`-поля, без сеттеров
