# Практические задания по многопоточности в Java

Этот каталог содержит практические задания для закрепления материала из статей по многопоточности.

## Структура проектов

### Основные практики (реализация с нуля)

Каждый модуль соответствует одной теме из курса:

- **practice-2**: Потокобезопасность — `synchronized`, `AtomicInteger`, `ReentrantLock`, `ReadWriteLock`, `Semaphore`
- **practice-3**: Совместное использование объектов — видимость, `volatile`, иммутабельность, `ThreadLocal`
- **practice-5**: Конкурентные коллекции — `ConcurrentHashMap`, `BlockingQueue`, `CopyOnWriteArrayList`
- **practice-6**: Синхронизаторы — `CountDownLatch`, `CyclicBarrier`, `Semaphore`, `FutureTask`
- **practice-7**: Выполнение задач — `Thread`/`Runnable`/`Callable`, жизненный цикл, прерывание, а также `CompletableFuture` (цепочки, композиция, обработка ошибок, тайм-ауты)
- **practice-8**: Применение пулов потоков — `ThreadPoolExecutor`, `ScheduledExecutorService`, параллельная обработка
- **practice-9**: Deadlock и Race Condition — дедлоки, гонки данных, упорядочивание блокировок
- **practice-10**: Производительность и масштабирование — закон Амдала, lock striping, параллельные вычисления
- **practice-11**: Тестирование конкурентных программ — safety-тесты, liveness, XOR-контрольные суммы
- **practice-12**: ForkJoinPool — `RecursiveTask`, `RecursiveAction`, work-stealing
- **practice-13**: Java Memory Model — `volatile`, happens-before, безопасная публикация, DCL
- **practice-14**: Виртуальные потоки — `newVirtualThreadPerTaskExecutor`, `Thread.ofVirtual()` *(требует Java 21+)*
- **practice-15**: Project Reactor — `Mono`, `Flux`, операторы, обработка ошибок

### Дополнительные практики

- **practice-debug**: Найди и исправь баг — задания на поиск проблем в готовом коде (race condition, deadlock, visibility)
- **practice-benchmarks**: Бенчмарки — примеры с замерами производительности, показывающие когда многопоточность ускоряет/замедляет

## Как работать с заданиями

### Требования

- Java 17+ (для `practice-14` требуется Java 21+ для виртуальных потоков)
- Maven 3.6+

### Инструкция

1. Перейдите в директорию нужного проекта:
   ```bash
   cd practice-1
   ```

2. Запустите тесты, чтобы увидеть, что нужно реализовать:
   ```bash
   mvn test
   ```

3. Откройте файл с тестами в `src/test/java/com/multithreading/practice/`
   - Прочитайте комментарии с требованиями
   - Изучите тесты, чтобы понять ожидаемое поведение

4. Создайте необходимые классы в `src/main/java/com/multithreading/practice/`
   - Реализуйте классы и методы так, чтобы все тесты проходили
   - **Не изменяйте сами тесты!**

5. Запустите тесты снова:
   ```bash
   mvn test
   ```

6. Когда все тесты проходят — задание выполнено! ✅

## Подсказки

- Читайте комментарии в тестах — они содержат требования и подсказки
- Изучайте примеры из статей — они помогут понять, как реализовать решение
- Не бойтесь экспериментировать — многопоточность требует практики
- Используйте отладчик для понимания порядка выполнения потоков

## Проверка решения

После реализации всех классов запустите:

```bash
mvn clean test
```

Все тесты должны проходить. Если тесты не проходят:
- Проверьте логи ошибок
- Убедитесь, что используете правильные механизмы синхронизации
- Проверьте, что правильно обрабатываете исключения
- Убедитесь, что правильно завершаете потоки и ExecutorService
